# Security Policy

## Reporting A Vulnerability

Do not report security vulnerabilities through public GitHub issues.

Use GitHub private vulnerability reporting for this repository when available.
If that channel is unavailable, open a minimal public issue asking maintainers
to enable a private reporting channel. Do not include exploit details, secrets,
logs, tokens, provider identifiers, or personal data.

Include reproduction steps, affected components, and impact only in the private
report.

## Sensitive Configuration

Do not commit provider credentials, publishable-key overrides, signing
material, keychain identifiers from private configuration, private endpoints,
tokens, or signed-runtime evidence.
